# 详细用法

[返回 README](../README.md)

## 添加入口

程序、快捷方式、文件夹和文档可直接拖入启动栏，也可以通过「＋」菜单选择文件。

「通过路径添加…」支持绝对路径、带引号的路径和 `%APPDATA%` 等环境变量。已有条目再次添加时会提示重复；路径比较忽略大小写、正反斜杠和 `.` / `..` 等写法差异。

文档通过系统默认程序打开。普通 EXE 如果已在运行且窗口可识别，Koi 会尝试切换到已有窗口；切换失败会提示，不会因此重复启动。带参数或自定义工作目录的快捷方式仍按原快捷方式启动。

## Microsoft Store 应用与自定义图标

Store 应用可以通过 `shell:AppsFolder` 入口启动，需要手动填写配置：

1. 在 PowerShell 运行 `Get-StartApps`，找到目标应用的 `AppID`。
2. 退出 Koi，备份 `%APPDATA%\Koi\config.xml`。
3. 在配置的 `<Items>` 中添加以下条目，把示例 AppID 和图标路径替换为本机实际值：

   ```xml
   <ItemCfg>
     <Name>应用名</Name>
     <Path>shell:AppsFolder\包标识!应用标识</Path>
     <Icon>C:\Koi\icons\app.png</Icon>
   </ItemCfg>
   ```

4. 保存后重新启动 Koi。

`Icon` 字段也可用于普通应用。图片需保留在指定路径；使用高清 PNG 可以改善旧程序的小图标在放大后发虚的问题。

如需提取已安装 Store 应用的图标，可通过 `Get-AppxPackage -Name <包名>` 查看 `InstallLocation`，再从其中的 `assets` 目录选择图片。目录和图片命名因应用而异。

## 开机自启动

先把 `Koi.exe` 放到固定目录，再右键启动栏空白处 → 勾选「开机自启动」。再次点击可关闭。

自启动记录的是开启时 EXE 的完整路径。移动文件后，需要重新关闭并开启自启动。开启过后，也可在 Windows 的「任务管理器 → 启动应用」中管理。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 看视频或全屏时启动栏仍在最前面 | 右键空白处，取消「总在最前」 |
| 想临时隐藏启动栏 | 当前没有隐藏热键或自动隐藏，可右键退出；下次启动会恢复配置 |
| 图标多了放不下 | 使用 `Shift + 滚轮` 横向滚动；拖动图标到边缘也会自动滚动 |
| 想调整大小、透明度 | 滚轮调整图标大小（32–112 逻辑像素），`Ctrl + 滚轮` 调整透明度（25%–100%） |
| 配置保存失败 | 查看 `%APPDATA%\Koi\errors.log` |
| 需要手动修改配置 | 先退出 Koi 并备份 `config.xml`，编辑完成后再启动 |
| 构建时提示输出文件正在使用 | 先退出该路径的 Koi 实例，再重新构建 |
| 找不到编译器或 WPF 程序集 | 检查并修复系统 .NET Framework |

## 当前能力范围

- **文件堆**：用于文档类文件，应用与文件夹不参与堆叠。可从悬停清单拖出单个成员，也可右键拆开整个文件堆。
- **文件夹预览**：后台读取，最多显示 40 个子目录；扫描前 5,000 个文件，选出其中最近修改的 6 个。超过上限会提示，超大目录不保证显示整个目录的最新文件。
- **预览缓存**：结果缓存 10 秒，最多保留 16 个目录，同时最多 2 个扫描。关闭或切换弹层会取消请求；已经进入系统的网络文件调用无法强制中断。
- **窗口切换**：依赖可访问的进程路径和顶层窗口。提权应用、特殊启动器与 Windows 前台限制可能阻止识别或切换；特殊快捷方式不保证复用窗口。
- **配置兼容**：新版保存文件堆成员的名称、图标和分组，同时兼容旧路径列表。旧配置未记录的信息无法恢复；降级前请备份配置，旧程序再次保存可能丢弃新字段。
- **桌面体验**：目前仅支持横向布局，没有全屏自动隐藏、隐藏热键或窗口预览。混合 DPI、多屏拔插、远程桌面和高对比度模式仍需按 [测试清单](testing.md#windows-桌面验收) 验证。
- **性能**：暂无固定硬件的性能基准。内存占用随图标数量、图片尺寸和操作变化；「立即释放内存」后的工作集下降不代表长期内存需求减少。
